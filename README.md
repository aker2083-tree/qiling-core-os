# qiling-core-os

自在光・靈覺｜器靈 Core OS — 長期認知代理架構（開發原型）。

## 先讀：靈主確認的核心總綱

**[器靈總綱與主從架構 V0.1](docs/QILING_CORE_CHARTER_V0.1.md)** 是無弦琴、影如風及千手秘協作時的共同語義錨點。請先閱讀，再解讀其他技術文件或提出架構修改。

核心定位：**靈主為語義本源；器靈為主體；伏藏為記憶根基；千手秘為執行體。** 千手秘以賈維斯式通用執行能力為願景；器靈以梅根式主動策略、莎曼薩式深層理解為願景。這些是研發目標，不代表現有模型已達 AGI／ASI。
